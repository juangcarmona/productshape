# Glossary

| Term | Definition |
| --- | --- |
| ESM | JavaScript's ECMAScript module format used across the workspace. |
| Monorepo | One version-controlled repository containing multiple packages with shared tooling and release coordination. |
| Provider renderer | Integration code that maps canonical ProductShape skills and commands to a tool-specific file format. |
| Workspace package | A package managed by the pnpm workspace and linked locally during development. |
| SDD | Spec-driven development; the specific product meaning is owned by the PDaC model and specification. |
| Static site | HTML, styles, scripts, and media generated at build time and served without an application server. |
