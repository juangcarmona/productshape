## Definition

A read-only published view of ProductShape's canonical architecture documentation, prepared for readers to navigate without editing the source documents.

## Distinguish From

The Product Snapshot is generated from the Product Definition model and describes product intent. The Architecture Snapshot is generated from ProductShape's architecture documentation and describes how ProductShape is designed. Neither is the canonical source for the other.

## Usage

The ProductShape engineering portal presents the Architecture Snapshot as a distinct output. ProductShape may use ArcShape, a separate product, to generate this view for its own documentation workflow.
