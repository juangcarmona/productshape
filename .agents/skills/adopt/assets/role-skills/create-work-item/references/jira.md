# create-work-item: Jira

Creation requires the project key, the issue type id, and every field the project marks required at creation: often including fields that appear on no screen the human ever sees.

Resolve during adoption and record in the configuration:

- the project key;
- the issue type id for the type the loop uses;
- each required custom field id and its accepted value shape;
- the parent field, where the project nests items under an epic or a feature.

Rich-text fields need a document structure, not a plain string.
