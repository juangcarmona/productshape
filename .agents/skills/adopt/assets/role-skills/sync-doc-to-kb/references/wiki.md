# sync-doc-to-kb: hosted wiki

Publishing replaces the page. Anything the page holds that the repository copy does not (an embedded diagram, a macro, an attachment reference) is destroyed unless it is carried across deliberately.

Update using the storage representation rather than a rendered form, and read the page first so what is about to be lost is known before the write.

Pulling the other way is an ordinary repository change: it goes through the normal branch and review flow, not straight onto the default branch.
